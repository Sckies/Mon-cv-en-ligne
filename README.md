# Mon-cv-en-ligne


Ce projet consiste à réaliser mon CV en ligne en utilisant HTML et CSS.

Le CV présente mon profil, mes compétences, mes formations ainsi que mes expériences professionnelles. Il est clair, structuré et s’adapter aux différentes tailles d’écran.

## Technologies utilisées

- HTML5
- CSS3
- Flexbox
- Media Queries

## Contenu du CV

- Profil
- Compétences
- Langues
- Qualités
- Centres d’intérêt
- Formations
- Stages
- Expériences professionnelles
- Liens vers les réseaux sociaux

## Responsive

Le CV s’adapte aux écrans de moins de 750px grâce à l’utilisation des Media Queries.
